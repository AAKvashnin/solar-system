# Солнечная система

Интерактивная 3D-модель на three.js: Солнце и все восемь планет, Луна, спутники Марса Фобос и Деймос, кольца Сатурна и Урана.

**Открыть: https://alekseybaranyuk.github.io/solar-system/**

- Планеты стоят на своих местах на текущую дату и движутся по кеплеровым орбитам (элементы JPL, эпоха J2000).
- Земля и Луна обращаются вокруг общего барицентра; фаза Луны считается по реальным положениям.
- Размеры планет между собой реальные; Солнце уменьшено в 3,6 раза, спутники Марса увеличены.
- Расстояния от Солнца по умолчанию сжаты (показан квадратный корень из расстояния); переключатель включает настоящие пропорции.
- Поверхности планет генерируются процедурно, без внешних картинок.

## Запуск

Откройте `index.html` в браузере. Нужен интернет: библиотека three.js загружается с CDN.

Управление: мышь вращает камеру, колесо меняет масштаб, кнопки внизу переключают тело в центре и скорость времени.
